# Excel 輸出契約 — 固定 35 分頁

Excel 是 `case_data.json` 的人用對帳視圖，不是另一份資料源。內容計算與視覺
樣式分離；預設中性樣式，使用者可指定 style adapter，但不得改變資料、來源、
狀態或分頁順序。


規則：

- 35 張全部存在且順序固定；額外頁只能接在其後。
- `complete`／`partial` 渲染資料列；partial 必須顯示原因。
- `missing` 保留分頁並顯示紅色「查無資料／須補件」。
- `not_applicable` 保留分頁並顯示灰色「不適用」，不能冒充缺件。
- `29_AI專家` 在 extractor 固定為不適用；不填投資意見。
- 逐項 IS／BS／CF 不得只留總額；每列須保留來源。
- `00_覆蓋率` 的 24 項狀態須與 `case_data.coverage` 相同。
- Excel `35/35` 只代表結構完整，不代表 24 項資料完整。

## 過渡引擎與依賴

目前 `scripts/build_excel.py`／`verify_excel.py` 是既有的 `openpyxl` 相容路徑，
依賴已列於 `requirements.txt`。OpenAI／Codex 原生工作簿引擎遷移是下一階段；
在完成前不得宣稱此路徑沒有 Python 套件依賴。
