# 台灣公開說明書 — 法定章節地圖 ＋ 萃取對照表

台灣公開說明書（TWSE/TPEx，依《公司募集發行有價證券公開說明書應行記載事項準則》）的章節**順序固定**。正因如此，萃取應「按章節定點抓」，而非整本略讀。本檔是 whitelist：只抓高訊號區塊，其餘（法遵聲明、承銷商/律師意見書全文、檢查表、公司治理運作細則）一律略過。

---

## A. 法定章節骨架（標準順序）

```
封面 / 摘要頁（高密度：實收資本、設立日、上市櫃日、會計師、董監持股、主要產品、市場結構、去年營收/稅前淨利/EPS）
壹、公司概況
  一、公司簡介：(一)設立日期 (二)地址電話 (三)公司沿革
  二、風險事項：(一)風險因素〔含「未來研發計畫及研發費用」〕(二)訴訟 (三)財務週轉/債信 (四)其他
  三、公司組織：(一)關係企業圖〔子公司+持股%+營運項目〕(二)董事及監察人 (三)總經理/副總/協理等經理人〔經營團隊〕
  四、資本及股份：(一)股本形成經過 (二)股權分散/主要股東 (三)每股市價淨值盈餘股利 (四)員工董監酬勞
貳、營運概況
  一、公司之經營：(一)業務內容〔產品/用途/產製過程/產業概況/上中下游/競爭情勢/研發成果/研發費用〕(二)市場及產銷概況〔銷售地區/產品營收比重/銷售量值/主要供應商/主要客戶/毛利率變化/員工人數〕
  二、轉投資事業
  三、重要契約
參、發行計畫及執行情形〔本次募資用途；VC 輪通常不適用，IPO 案則為資金用途實表〕
肆、財務概況
  一、最近五年度簡明財務資料〔個體＋合併：IS/BS/財務分析比率/查核意見〕
  二、財務報告應記載事項〔指向附件查核財報〕
  四、財務狀況及經營結果之檢討分析〔財務狀況/績效/現金流/重大科目變動/資本支出/轉投資政策〕
伍、特別記載事項〔★多為 boilerplate，預設略過，例外見下〕
附件：查核簽證之合併＋個體財務報告〔★常為掃描檔 → Vision〕、發行辦法、檢查表
```

*註：章節編號因案件類型而異（員工新股/現金增資/初次上市櫃），初次上市櫃格式最細（員工人數、產製過程、銷售量值常獨立成節）。一律以 slicer `index.md` 實際標題為準。*

## D. 預設略過（低訊號法遵樣板，不入 factbase）

- 封面法遵聲明、有價證券生效不得作宣傳、分送計畫、股務代理/簽證/評等機構聯絡資訊
- 伍、特別記載事項之：內部控制聲明、承銷商評估總結意見**全文**、律師法律意見書、案件檢查表彙總意見、各式「不得退還費用/不得配售關係人」聲明書、公司治理運作情形細則、永續發展/誠信經營守則差異
- 陸、重要決議之章程新舊條文對照、盈餘分配表全文（僅摘關鍵）
- 附件之發行辦法、檢查表

例外保留：承銷商評估意見**若含財務預測數字**→ 抓那張表（標來源＝承銷商預估，可信度分類 E）；公司治理「董事長兼總經理」「辭任彙總」→ 一句話帶治理紅旗。

## E. VC 用途的關鍵提醒

公開說明書是**歷史/營運面（A–F）最完整**的單一文件，但：

1. **G 本輪條件（Term Sheet/估值/IPO 時程）通常不在裡面** — 公開說明書是「公開發行/員工新股/初次上市櫃」用途，非 VC 募資。G 仍須由 data room 其他文件補。萃取器在 coverage 報告把 G 標「prospectus 不涵蓋，須他檔補」。
2. **財報是查核「個體＋合併」** — 餵 evaluator 時注意 A0-4：營運數字取營運實體，勿用投資控股殼；無子公司則僅個別財報。
3. **公司自引的市場規模/市佔** — 標「circular，需 Phase3 獨立查驗」，不可當事實。
4. **供應商/客戶代號** — 公說常以甲乙丙或 A/B 客戶表示，**標「代號，可從 data room 對照真名」**；若具名且為關係人（如向母集團採購），直接 🔴 並記進貨/銷貨比。
5. **數字單位** — 多為「仟元」，務必逐筆標單位。
